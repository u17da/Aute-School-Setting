# Avatar（アバター）

まなびポケット Design System — ユーザー識別コンポーネント

## いつどれを使うか

| シナリオ | variant | 理由 |
|---|---|---|
| コメント横、一覧のアイコン | `avatar`（アイコンのみ） | 省スペース |
| 投稿者表示、ユーザー選択 | `named`（アイコン＋名前） | 識別しやすい |
| プロフィール写真未設定 | `initial`（頭文字生成） | 自動フォールバック |

## Sizes

| size | 直径 | テキスト | 名前テキスト | 用途 |
|---|---|---|---|---|
| `s` | 24px | 14px | 14px (Medium) | 一覧、コンパクト表示 |
| `m` | 36px | 21px | 16px (Large) | 標準表示、コメント |
| `l` | 48px | 28px | 18px (X-Large) | プロフィール、詳細 |

## 表示パターン（variant）

### ProfilePic（アイコンのみ）

| パターン | 表示 | 条件 |
|---|---|---|
| 写真あり | 円形にクロップした画像 | `src` が有効 |
| 写真なし | `#008299` 背景 + 頭文字（白） | `src` なし / エラー |

### Name（アイコン＋名前）

```
[🟢 写真] 山田太郎
```

| size | アイコンと名前の gap |
|---|---|
| s | 4px |
| m | 8px |
| l | 16px |

## スタイル詳細

| 要素 | 値 |
|---|---|
| 画像クリップ | `border-radius: 50%` (完全な円) |
| フォールバック背景 | `#008299` |
| フォールバック文字色 | `#FFFFFF` |
| フォールバック文字 | アカウント名の先頭1文字 |
| フォールバック font-weight | 600 |
| 名前テキスト色 | `#283148` |
| 名前テキスト weight | 300 |
| 画像 object-fit | `cover` |

## Figma に含まれる人物バリアント

| プロパティ名 | 種別 | 説明 |
|---|---|---|
| 山田太郎、佐藤宏、新井花子、伊藤綾 | 写真あり | 生徒・保護者イメージ |
| 先生01 | 写真あり | 教職員イメージ |
| アイコン_上、アイコン_木、アイコン_工 | 頭文字 | 写真未設定時のフォールバック |

## Do / Don't

| ✅ Do | ❌ Don't |
|---|---|
| 原則名前と共に表示する | 小さいアイコンのみで誰か分からない |
| 写真未設定時はフォールバックを使う | 空白や「?」を表示する |
| size を用途に合わせて選ぶ | 全て同じサイズで使う |
| 円形を維持する | 角丸四角で代用する |

## アクセシビリティ

- `<img>` に `alt="{ユーザー名}"` を設定
- フォールバック（頭文字）時は `aria-label="{ユーザー名}"` を設定
- クリック可能な場合は `role="button"` + `tabindex="0"`
- 装飾的な場面（名前テキストが隣接する等）では `alt=""` で空にする

## 実装スニペット

```tsx
import { Avatar } from '@manabi-ds/avatar';

// 1. 写真あり（アイコンのみ）
<Avatar src="/photos/yamada.jpg" name="山田太郎" size="m" />

// 2. 写真なし（頭文字フォールバック）
<Avatar name="上田一郎" size="m" />

// 3. アイコン＋名前
<Avatar src="/photos/yamada.jpg" name="山田太郎" size="m" showName />

// 4. 小サイズ（リスト内）
<Avatar name="佐藤宏" size="s" showName />
```
