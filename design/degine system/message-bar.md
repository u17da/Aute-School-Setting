# MessageBar（全幅メッセージバー）

まなびポケット Design System — フィードバックコンポーネント

## いつどれを使うか

| シナリオ | コンポーネント | 理由 |
|---|---|---|
| ユーザー操作の成否を即座に伝える | Message | 一時的表示・自動消失 |
| **サイト全体の重要告知** | **MessageBar** | 画面最上部、全幅、高優先度 |
| コンテンツエリア内の注意書き | Alert | 対象コンテンツ上部に配置 |
| 情報を常設バナーで提示 | InfoBanner | 画面下部に配置 |

## Variants（color プロパティ）

| color | 背景色 | テキスト色 | 用途 |
|---|---|---|---|
| `alert` | `#C53F3F` | `#FFFFFF` | 緊急・エラー系のサイト全体告知 |
| `black` | `#283148` | `#FFFFFF` | 汎用の重要告知 |

## 構造

```
┌─────────────────────────────────────────────────┐
│  メッセージテキスト（中央揃え）           [×]   │
└─────────────────────────────────────────────────┘
```

- 全幅 100%、高さ 48px
- padding: `12px 20px`
- テキスト: 16px / weight 300 / line-height 1.5 / `text-align: center`
- 閉じるアイコン: 24×24、白色

## 配置ルール

- 画面の最上部に配置（ヘッダーより上）
- 画面全体にかかる形で `width: 100%`
- 固定表示（スクロールしても追従）が推奨
- 複数バーの同時表示は原則禁止、1つに統合する

## States

- **visible** — 表示中
- **hidden** — 閉じるボタンで非表示（セッション内は再表示しない）

## Do / Don't

| ✅ Do | ❌ Don't |
|---|---|
| サイト全体に影響する重要な告知に使う | ユーザー個別の操作結果に使う（→ Message を使う） |
| 1〜2行以内の簡潔なメッセージにする | 長文の説明を入れる |
| 閉じるボタンを必ず付ける | 閉じる手段なしで永続表示する |
| `alert` は本当に緊急時のみ使う | 通常のお知らせに `alert` を使う |

## アクセシビリティ

- `role="banner"` + `aria-live="polite"`
- 閉じるボタンに `aria-label="閉じる"`
- 背景色とテキスト色のコントラスト比 4.5:1 以上（白 on #C53F3F = 4.64:1 ✓）
- キーボード操作で閉じるボタンにフォーカス可能

## 実装スニペット

```tsx
import { MessageBar } from '@manabi-ds/message-bar';

<MessageBar color="alert" onDismiss={handleClose}>
  メンテナンスのため、本日22時よりサービスを停止します。
</MessageBar>

<MessageBar color="black">
  新学期の設定を忘れずに行ってください。
</MessageBar>
```
